# Home Assistant Blueprints

Reusable Home Assistant automation blueprints.

## Blueprints

| Blueprint | Description | Import |
| --- | --- | --- |
| [Device error notification](blueprints/automation/device-error-notification.yaml) | Notifies when a device reports an error. | [![Open your Home Assistant instance and show the blueprint import dialog with a specific blueprint pre-filled.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fgithub.com%2Fysmilda%2Fhome-assistant-blueprints%2Fblob%2Fmain%2Fblueprints%2Fautomation%2Fdevice-error-notification.yaml) |
| [PrusaLink print live activity](blueprints/automation/prusalink-live-update.yaml) | Shows a PrusaLink print as a Live Activity. | [![Open your Home Assistant instance and show the blueprint import dialog with a specific blueprint pre-filled.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fgithub.com%2Fysmilda%2Fhome-assistant-blueprints%2Fblob%2Fmain%2Fblueprints%2Fautomation%2Fprusalink-live-update.yaml) |

## Installing

In Home Assistant, go to **Settings → Automations & Scenes → Blueprints →
Import Blueprint** and paste the GitHub URL of the blueprint file, or copy the
file into `config/blueprints/automation/<namespace>/` and reload automations.
